# FinSight - Financial Analytics Platform

A comprehensive financial analytics dashboard for analyzing Microsoft (MSFT) and Netflix (NFLX) stock performance from 2020-2024.

## Features

- **Maximum Drawdown (MDD) Analysis**: Calculate drawdown percentages from rebased stock values
- **WACC Calculations**: Weighted Average Cost of Capital analysis for debt percentages 0-99%
- **Beta Analysis**: Unlevered and relevered beta calculations
- **Cost of Capital**: Cost of Equity and Cost of Debt computations using CAPM
- **Interactive Visualizations**: Area charts for MDD and line charts for WACC vs Debt %
- **Stock Comparison**: Side-by-side comparison of MSFT and NFLX metrics
